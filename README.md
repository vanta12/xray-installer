# Autoscript Xray

Install:

```bash
curl -fsSL https://raw.githubusercontent.com/vanta12/xray-installer/main/bin/install | sudo bash
```

Input: domain kamu. Setelah itu link otomatis tercetak.

Setelah terpasang, ketik `menu` untuk kelola user (tambah/hapus/perpanjang/link).

Uninstall:

```bash
sudo uninstall
```
